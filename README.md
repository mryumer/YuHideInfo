# YuHideInfo

Клиентский мод для Minecraft 1.21.11 (Fabric), который скрывает IP-адрес сервера
в полях ввода, пока вы сами не решите его показать.

## Что делает мод

- В экране **«По адресу»** (`DirectConnectScreen`) и в экране **добавления/изменения
  сервера** (`AddServerScreen`) рядом с полем IP появляется квадратная кнопка 16×16.
- По умолчанию адрес отображается звёздочками (`*`). Нажатие на кнопку показывает
  настоящий IP, повторное нажатие снова скрывает его.
- Настоящий текст поля никогда не подменяется: при подключении и сохранении сервера
  используется реальный адрес.
- Состояние сбрасывается в «скрыто» при каждом открытии экрана.

## Сборка

Требования: JDK 21+.

```bash
gradlew build
```

Готовый мод появится в `build/libs/yuhideinfo-1.0.0.jar`.
Положите его в папку `mods` вместе с Fabric Loader и Fabric API.
